Changing the README table from "| 1 |" to "| I |" switched off C9's page-count
check.  The loop keys on the row label and answered a missing row with `continue`,
so four page counts stopped being verified and the suite still said all checks
pass.  Third instance today of a check that stopped looking without saying so, and
the first one caused while holding the lesson.  The lesson is not that the rule is
easy to forget: `continue` is what you write for a case you have not thought about,
and it is indistinguishable from a pass.  A missing row now fails by name, and the
row count goes through expect_subjects.
