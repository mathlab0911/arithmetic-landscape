about a licence line, and then walked into it in a JSON field. Writing the rule down did not
install it. What was missing is a trigger, and the trigger is now written into the ledger as
the question that must be answered before a tag is pushed: WHAT DID THIS RELEASE MAKE FALSE?

homepage, the previous version's release notes -- can carry a superseded claim, and none of
them are checked by C1-C20, because none of them are the paper.
