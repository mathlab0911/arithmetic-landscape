## 1. E2a【最優先】中心外の lm/deg(剛性 vs ドリフト)

- 対象: A = 最初の k 個の奇素数(論文と同じ規約)、T = ΣA、n_ρ = ⌊ρT⌋
- 計算: **厳密整数DP** で deg_A(n_ρ) と lm_A(n_ρ)(lm は定理19の層別公式=既存DP流用)
- 格子: ρ ∈ {0.30, 0.35, 0.40, 0.45, 0.50}、k = 16..26
- **無料の正しさ検査**: 反転定理により lm(n) = lm(T−n) 厳密。ρ=0.45 と 0.55 で
  **完全一致すること**(1件でも不一致ならDPのバグ)
- **粒度ガード(V2d)**: deg(n_ρ) < 10⁴ の格子点は判定に使わない(小整数の比は暴れる)。
  各点の生の deg, lm を必ずログに(V2c)
- 判定表: ratio(ρ,k) = [lm/deg] ÷ Γ(P_k)。各 ρ 列で k↑ のとき 1 に向かうか(R)、
  ρ ごとに別の値へ向かうか(D)。「向かう」の判定は k で単調性を見る(V3: 範囲が
  足りなければ k を伸ばしてから言う)

## 2. E2b【第2】レート関数の普遍性

- Î_k(ρ) := −(1/k)·log₂は使わず自然対数: −(1/k)·ln(deg_A(⌊ρT⌋)/2^k)
- 参照列: L_k = 最初の k 個の奇数 1,3,...,2k−1(パリティ一致・プロファイル厳密線形)
- 比較: D_k(ρ) = Î_k^{素数}(ρ) − Î_k^{奇数}(ρ)。deg だけなので k = 16..40 まで
- 予想(普遍性): D_k(ρ) → 0、レートは loglog k / log k 級、符号は全 ρ で一定
- 報告: 表(ρ×k)+ 符号 + 減衰の当てはめ(指数は当てず「単調減少+符号一定」の確認まで)

## 3. E3【第3】バイアス硬貨で Γ_x を実現する

- 重み付き数: deg_q(n) = Σ_{S:σ(S)=n} q^{|S|}(1−q)^{k−|S|}、lm_q は同じ和を
  局所最小 S に制限(分類定理は測度に依らないので S 集合は同じ)
- 実装: 浮動小数DPでよいが、**1点(k=20, q=0.4)だけ分数演算で照合**(V1の精神)
- 中心: n*_q = argmax_n deg_q(n)(≈ qT)。測定: ratio_q = lm_q(n*_q)/deg_q(n*_q)
- 格子: q ∈ {0.30, 0.40, 0.50, 0.60, 0.70}、k = 16..24
- 判定: ratio_q を Γ_x(A) = (1−x)Σ a_j x^{j−1}(x を自由パラメータ)に当て、
  経験則 x(q) を抽出して報告(候補: x=q / x=1−q / x=min(q,1−q)。**どれかは予断しない**。
  q=0.5 で x=0.5=Γ に戻ること、q↔1−q の対称性の有無が最初のチェック)
- fableはデータを見てから x(q) の公式を導出する(理論側の宿題)
